# luck

واجهة بسيطة تعرض بوب أب لعجلة حظ عربية تحتوي على خمسة اختيارات مبهجة مع احتمالين فقط لرموز الخصم. لبدء التجربة شغّل أي خادم ملفات ثابتة (مثل `npx serve` أو `python -m http.server`) ثم افتح `index.html` في المتصفح.

## المزايا
- عجلة حظ أنيقة مع حركة دوران سلسة ومؤثر بصري يشبه البوب أب.
- عرض نتيجة فورية مع إبراز أكواد الخصم عندما تكون هي الفائزة.
- زر لنسخ كود الخصم مع دعم بديل للمتصفحات التي لا توفر `navigator.clipboard`.
